## ⚙️ Como usar

### 1. Clone o repositório

```bash
git clone https://github.com/lucasnpiana/bootcamp-javascript.git
```

### 2. Acesse a pasta do módulo desejado

```bash
cd bootcamp-javascript/15-js-navegador
```

### 3. Execute o arquivo via Node.js ou abra no navegador

```bash
node 01-selecionando-elementos-dom.js
```

> 💡 **Dica:** Arquivos que utilizam o DOM (`document`, `window`) devem ser executados no navegador através do arquivo `.html` correspondente ou com a extensão **Live Server** no VS Code.
